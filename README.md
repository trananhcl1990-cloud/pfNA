# Caloha Website Listening

Dashboard phân tích CSV Google Search Console: nhóm chủ đề, so sánh hai kỳ, phát hiện cơ hội SEO, brief và quản lý task.

## Chạy
Mở `index.html` bằng trình duyệt hoặc phục vụ thư mục qua một static web server. Không cần dependency hay build. Có thể triển khai trên GitHub Pages.

## Dữ liệu
Nhập CSV với các cột Query, Clicks, Impressions, Position; Page/URL tùy chọn. Dữ liệu mẫu chỉ dùng minh họa. Dữ liệu và task lưu trong localStorage; dùng sao lưu JSON trước khi chuyển máy hoặc xóa dữ liệu trình duyệt.

## Phạm vi
Chưa tích hợp GSC API, LLM, đồng bộ nhiều người dùng hoặc dữ liệu chuyển đổi. Các tín hiệu là đề xuất cần kiểm chứng, không đại diện toàn bộ nhu cầu thị trường.
